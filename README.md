Sistema de Gerenciamento de Biblioteca em Java.

Sistema de console que permite o cadastro dinâmico de livros, controle de estoque (disponibilidade) e simulação de taxas de locação com base no ano de publicação.

O que aprendi: Aplicação da OOP (Object Oriented Programming), Arrays Dinâmicos com ArrayList, Aplicação de tratamentos de Buffer (scanner:NextInt()), controle de fluxo com Loops Aninhados e refatoração para métodos mais limpos.
